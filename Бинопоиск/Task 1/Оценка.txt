int calc(int* arr, int size)
{
  int ans = 0;
  for (int i = 1; i < size; i++)
  {
    ans += arr[i] - arr[i-1];
  }
  return ans;
}



1. Функция принимает указатель на массив целых чисел и его размер.

В переменной ans накапливается результат.

Цикл проходит от индекса 1 до size - 1 включительно.

На каждой итерации к ans прибавляется разность между текущим и предыдущим элементом: arr[i] - arr[i-1].

После завершения цикла функция возвращает ans.

2. O(n), где n = size

Цикл выполняется ровно - 1 итераций.

Количество итераций линейно зависит от размера входных данных.

На каждой итерации выполняется константное количество операций:

два обращения к массиву по индексу;

операция вычитания;

операция сложения.



3. O(1) (константная)

В функции используется только одна целочисленная переменная ans для хранения промежуточной суммы.

Дополнительная память не выделяется динамически.

Объём используемой памяти не зависит от размера входного массива.

Все операции выполняются непосредственно с переданным массивом без создания копий или вспомогательных структур.
