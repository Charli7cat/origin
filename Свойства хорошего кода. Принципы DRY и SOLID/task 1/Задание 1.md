1\. Класс Data нарушает контракт интерфейса Printable

Методы printAsHTML(), printAsText() и printAsJSON() в базовом интерфейсе объявлены как виртуальные и предполагают что их можно вызывать в любой момент, но в классе Data каждый из этих методов выбрасывает исключение std::runtime\_error



2\.  Класс Data и функция saveTo не закрыты для модификации при добавлении новых форматов

то есть код не расширяется путём добавления новых классов, а требует изменения существующих классов и функций 

это прямое нарушение OCP



3\. Интерфейс Printable является fat interface и содержит методы которые не нужны всем реализациям

Интерфейс Printable требует реализации трёх методов вывода, а в классе Data каждый метод имеет смысл только при определённом состоянии объекта и если бы мы захотели создать класс который умеет выводить только в HTML нам всё равно пришлось бы реализовывать printAsText и printAsJSON
