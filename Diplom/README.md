# Поисковая система по текстовым документам (Qt + PostgreSQL)

## Описание
Проект состоит из двух приложений:
1. **Indexer** — консольное приложение для рекурсивной индексации текстовых файлов и сохранения статистики в БД PostgreSQL.
2. **Searcher** — графическое приложение (Qt Widgets) для поиска документов по ключевым словам с ранжированием по частоте упоминания.

## Требования
- Qt 6 (модули Core, Gui, Widgets, Sql)
- PostgreSQL 14+
- Драйвер QPSQL (поставляется с Qt)

## Настройка
1. Создайте базу данных в PostgreSQL: `CREATE DATABASE searchdb;`
2. Отредактируйте `config.ini` (укажите свои данные для подключения к БД и путь к папке с документами).
3. Скопируйте `libpq.dll`, `libssl-*.dll`, `libcrypto-*.dll` из папки `bin` PostgreSQL в папки сборки приложений (рядом с `.exe`).
4. Соберите проекты через Qt Creator (qmake).

## Использование
1. Запустите `indexer.exe`. Он создаст таблицы и проиндексирует файлы из указанной папки.
2. Запустите `searcher.exe`. Введите запрос (до 4 слов) и нажмите «Искать».
